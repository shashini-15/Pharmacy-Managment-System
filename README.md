## 💊 Pharmacy Management System

A full-stack web application designed to streamline pharmacy operations including inventory management, user handling, prescription processing, and reporting.

## 🚀 Project Overview

This system helps pharmacies manage daily operations efficiently by providing:

Medicine inventory tracking
User role management (Admin, Pharmacist, Customer)
Prescription-based order processing
Sales and inventory reporting

Built as part of an academic project using modern full-stack technologies.

## 🛠️ Tech Stack
Backend
Java (Spring Boot)
Spring Security & JWT Authentication
Spring Data JPA
MySQL
Frontend
React (Vite)
Axios
HTML, CSS, JavaScript

## ✨ Features
## 👤 User Management
User registration & login
Role-based access control (Admin / Pharmacist / Customer)
Manage users (add, update, delete)
## 💊 Inventory Management
Add, update, delete medicines
Track stock levels
Expiry date monitoring
Low stock alerts
## 📦 Order & Prescription Management
Place orders (with/without prescription)
Upload prescriptions
Order status tracking
Order history

## 📊 Dashboard & Reports
Sales reports
Inventory reports
Low stock & expiry alerts

## 🔐 Security
Secure login authentication (JWT)
Role-based authorization
Protected APIs
Encrypted user data

## ⚙️ Installation & Setup
🔹 Backend Setup
cd backend
mvn clean install
mvn spring-boot:run
🔹 Frontend Setup
cd frontend
npm install
npm run dev
